# 闪碟外卖 · 点餐下单交互原型

移动端 H5 外卖点餐原型，单文件、零依赖、离线可跑。用于演示一条**完整的外卖购买链路**。

> ⚠️ 纯前端模拟：所有店铺、菜品、价格、订单均为本地 mock 数据，
> 不发任何网络请求、不接入支付 SDK、**不会产生真实订单或扣款**。刷新页面即恢复初始状态。

## 使用方式

直接用浏览器打开 `index.html` 即可。桌面端会显示手机外壳 + 操作说明，移动端自动铺满全屏。

## 覆盖的流程

首页/定位 → 分类筛选 → 店铺列表 → 店铺详情点菜（多规格 + 加料）→ 购物车
→ 确认订单（地址 / 配送方式 / 送达时间 / 优惠券 / 餐具 / 备注 / 发票 / 支付方式）
→ 选支付方式 → 模拟支付密码 → 支付中 → 下单成功
→ 骑手实时配送地图 + 5 阶段进度 → 订单详情 → 确认收货 → 评价晒单（发券）

## 功能要点

| 模块 | 说明 |
| --- | --- |
| 首页 | 定位栏、搜索、8 格金刚区、活动 banner、限时秒杀倒计时、5 种排序 + 2 个筛选、6 家店铺 |
| 搜索 | 热搜词、历史搜索、菜品命中 + 店铺命中双结果、空结果态 |
| 店铺页 | 品牌头图、商家信息、公告、满减标签、优惠券领取、左侧分类锚点（带角标） |
| 点菜 | 多规格弹层（份量/辣度/温度/甜度，含差价）+ 多选加料、份数、单价实时重算 |
| 购物车 | 悬浮购物车条（角标/合计/已减/差多少起送）、增删改、跨店加购提示、清空确认 |
| 结算 | 地址增删改、标准配送 / 准时达 / 到店自取、送达时段、**自动比价选最优券**、券可用与不可用分组 |
| 费用 | 小计 + 包装费（按份）+ 配送费 − 店铺满减（多档取最优）− 优惠券 − 新客立减，全链路实时联动 |
| 支付 | 微信 / 支付宝 / 银行卡 / 货到付款，模拟密码键盘 → loading → 成功动画 |
| 配送 | SVG 街景地图、骑手沿路径移动、5 阶段进度条、物流日志、自动推进 + 加速演示、取消订单 |
| 订单 | 列表（全部 / 进行中 / 已完成）、详情全量费用、评价（星级 + 标签 + 文本，提交发无门槛券） |
| 我的 | 会员卡、余额 / 券包 / 积分 / 收藏、地址管理、重置演示数据 |

## 技术说明

- 单个 HTML 文件，原生 HTML + CSS + JavaScript，无框架、无构建、无外部资源
- 自实现屏幕栈路由（push / below / pop 转场动画）
- 菜品图使用 emoji + 渐变色块占位，可按需替换为真实图片
- 品牌「闪碟外卖」为虚构名称，配色独立，未使用任何现有平台的品牌视觉
